# 自由职业费率计算器

**你到底该收多少钱？输入 5 个数字，10 秒算出你的保底时薪。**

🔗 **在线使用：<https://hahaknight.github.io/freelance-rate-calculator-cn/>**

## 为什么需要它

大多数自由职业者定价的方式是"猜一个听起来能接受的数"——然后在交税时才发现，这个数其实低于最低工资。这个计算器反过来推：从你**真正需要**的收入出发，减去现实成本，得出你的**保底时薪**——低于它，这个项目就在让你倒贴。

5 个输入：

| 输入项 | 它代表什么 |
|---|---|
| 目标每月到手收入 | 你要替代的工资 |
| 每月经营成本 | 软件、硬件、保险、办公 |
| 每周可计费小时数 | 按现实情况估——不是所有工时都能收费 |
| 每年工作周数 | 扣掉假期、生病、空窗期 |
| 预估税 + 社保 | 最容易被忘掉的部分 |

输出：一个有依据的最低时薪。高于它报价；低于它接单前你会知道。

全部计算**在浏览器本地完成**——不用注册、没有服务器、你的数字不会离开这个页面。English version: [freelance-rate-calculator](https://github.com/Hahaknight/freelance-rate-calculator).

## 自部署

单个静态 `index.html`，零依赖。

```bash
git clone https://github.com/Hahaknight/freelance-rate-calculator-cn
# 直接打开 index.html，或在你 fork 的仓库开启 GitHub Pages
```
